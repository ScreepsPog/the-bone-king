# Dev log

How this game was built during the 2026 Epic AI MegaJam, one entry per work session.

## Files

`YYYY-MM-DD-NN-short-title.md`, where `NN` is the session number that day.

## Each entry, in this order

0. **When**: every entry and every dated line carries a date and time, as `YYYY-MM-DD HH:MM PST`.
1. **Asked**: what the director (Screeps) asked for, in their words where possible.
2. **What the agents did**: the steps taken and the commits made.
3. **What failed and the fix**: errors, wrong turns, and how each was resolved.
4. **Screenshots**: images or clips, stored in `DevLog/Images/`.
5. **Time spent**: wall-clock time for the session.
